# Библиотека текстов

Здесь лежат оригиналы текстов человека — главный образец голоса. Агент копирует из них ритм,
длину фраз, переходы, слова. Правила в `agent/voice.md` вторичны, тексты первичны.

Один файл — один текст. Имя: `ГГГГ-ММ-ДД-тема.md` (тема на английском, коротко).

В начале файла три строки:

```
Где: канал или формат (пост в Telegram, письмо клиенту, рилс)
Источник: оригинал / одобрен без правок / одобрен после правок
Дата: ГГГГ-ММ-ДД
```

Ниже — текст целиком, без изменений.

Добавлять только:

- по команде человека «в библиотеку», «сохрани как образец»;
- на настройке (шаг 3 `agent-setup`);
- когда человек одобрил текст агента без правок и ответил «да» на вопрос «Добавить в библиотеку?».

Агент сам тексты из библиотеки не правит и не удаляет.
