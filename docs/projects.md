# Этап 2. Проекты

Тематический проект — отдельный проект в Cowork под одну тему: здоровье, финансы, контент,
конкретный клиент, учёба. Заводить их не обязательно. Начни с одного агента и выноси тему в
отдельный проект, когда к ней постоянно возвращаешься и её записи засоряют общий журнал.

## Как устроено

```
Документы/
  Мой агент/            основной проект: профиль, правила, уроки, общий журнал
  Мой агент — здоровье/ тематический проект: свои инструкции, журнал, решения
  Мой агент — контент/  тематический проект
```

В тематическом проекте подключены две папки: сначала его собственная, потом основная папка
агента. Из основной агент берёт профиль, правила и уроки, поэтому тебя не нужно описывать заново,
а урок, полученный в одном проекте, действует во всех. Журнал и решения у каждого проекта свои.

Папки тематических проектов лежат рядом с основной, а не внутри неё. Так проект «Контент» не
видит файлов «Здоровья».

## Как завести

В основном проекте напиши `/new-project`. Агент спросит название, цель и правила проекта, создаст
папку в `projects/` и объяснит, как вынести её наружу и подключить отдельным проектом.

## Облачные проекты и проекты из папки

- **Проект из папки** (Use an existing folder) работает с файлами на твоём компьютере. Агент
  читает и пишет их, пока открыто приложение. Этот кит устроен так.
- **Облачный проект** (Start from scratch) создаёт новую пустую папку. Anthropic сейчас
  переносит такие проекты в аккаунт claude.ai, и правила для них меняются. Для этого кита он не
  нужен: память агента живёт в твоей папке.

Встроенная память проекта в Cowork есть в обоих вариантах, но она пропадает, если проект
заархивировать. Файлы в папке остаются, поэтому главная память агента — в них.

## Чувствительные данные

Всё, что лежит в папке проекта, агент читает и отправляет модели при работе. Для проектов
«Здоровье» и «Финансы» особенно:

- не клади пароли, коды, номера карт, сканы паспорта;
- анализы, выписки и документы — только те, что нужны для конкретной задачи;
- агент не платит и не переводит деньги ни в каком проекте, этот запрет стоит в `agent/rules.md`.
