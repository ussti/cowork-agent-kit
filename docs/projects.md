# Этап 2. Проекты

Тематический проект — отдельный проект в Cowork под одну тему: здоровье, финансы, контент,
конкретный клиент, учёба. Заводить их не обязательно. Начни с одного агента и выноси тему в
отдельный проект, когда к ней постоянно возвращаешься и её записи засоряют общий журнал.

## Как устроено

```
Документы/
  Мой агент/              основной проект: профиль, правила, уроки, общий журнал
  Мой агент — здоровье/   тематический проект: свои инструкции, журнал, решения
  Мой агент — контент/    тематический проект
```

Агент один, а проектов несколько. Это работает, потому что в каждом тематическом проекте
подключены две папки:

1. **Первая — папка самого проекта.** Здесь его инструкции, журнал и решения, сюда агент кладёт
   новые файлы.
2. **Вторая — «Мой агент».** Отсюда агент берёт твой профиль, правила и уроки.

Поэтому тебя не нужно описывать заново, а урок, полученный в одном проекте, действует во всех.
Журнал и решения у каждого проекта свои.

Папки тематических проектов лежат рядом с «Моим агентом», а не внутри него. Так проект «Контент»
не видит файлов «Здоровья».

## Как завести проект

Пример для проекта «Здоровье». Для любого другого всё так же, меняется только название.

### 1. Создай пустую папку

В **Finder** на Mac или в **Проводнике** на Windows открой папку, где лежит «Мой агент»
(например, **Документы**). Создай рядом новую папку: на Mac — правой кнопкой → **Новая папка**,
на Windows — правой кнопкой → **Создать** → **Папку**. Назови её:

```
Мой агент — здоровье
```

> [!IMPORTANT]
> Новая папка лежит рядом с «Моим агентом», а не внутри него.

### 2. Создай проект из этой папки

1. В Cowork открой **Projects** и нажми **+**.
2. Выбери **Use an existing folder** и укажи новую папку «Мой агент — здоровье».
3. Назови проект:

   ```
   Здоровье
   ```

### 3. Подключи вторую папку

В настройках проекта добавь вторую папку — «Мой агент».

> [!WARNING]
> Первой должна остаться папка «Мой агент — здоровье»: в первую папку Cowork кладёт новые файлы.

### 4. Вставь инструкцию проекта

В поле инструкций проекта вставь строку:

```
Перед любой задачей прочитай CLAUDE.md в первой папке проекта, затем CLAUDE.md основной папки агента, и следуй им.
```

Сохрани.

### 5. Запусти настройку проекта

Начни в новом проекте задачу и напиши:

```
/new-project
```

Агент спросит, зачем проект, какие файлы туда пойдут и есть ли особые правила. Потом он создаст
в папке проекта инструкции, журнал и решения и отметит новый проект в «Моём агенте».

### 6. Проверь

Начни новую задачу и спроси:

```
Какой это проект и что ты обо мне знаешь?
```

Агент должен назвать проект и пересказать твой профиль.

## Где правда, если проекты расходятся

- Профиль, правила и уроки — только в «Моём агенте». Правишь их там, и правка действует во всех
  проектах.
- Журнал и решения — в папке каждого проекта. В «Моём агенте» остаются только общие задачи.
- Уборку запускай в каждом проекте отдельно: она убирает журнал того проекта, в котором открыта.
  Уборку по расписанию можно поставить на каждый проект, указав его папку в поле **Folder**.

```
/memory-cleanup
```

## Варианты создания проекта

- **Use an existing folder** работает с файлами на твоём компьютере. Агент читает и пишет их,
  пока открыто приложение. Этот кит устроен так.
- **Start from scratch** создаёт новую пустую папку, а **Import a project** переносит проект из
  обычного чата claude.ai. Для этого кита они не нужны: удобнее самой создать папку рядом с
  «Моим агентом», чтобы знать, где лежит память.

Проекты Cowork хранятся только на твоём компьютере. В облако они не синхронизируются, и
другие люди их не видят.

У проекта есть встроенная память, но при архивации проект теряет название, инструкции и эту
память. Файлы в папке остаются, поэтому главная память агента — в них.

## Чувствительные данные

> [!CAUTION]
> Всё, что лежит в папке проекта, агент читает и отправляет модели при работе.

Для проектов «Здоровье» и «Финансы» особенно:

- не клади пароли, коды, номера карт, сканы паспорта;
- анализы, выписки и документы — только те, что нужны для конкретной задачи;
- агент не платит и не переводит деньги ни в каком проекте, этот запрет стоит в `agent/rules.md`.
