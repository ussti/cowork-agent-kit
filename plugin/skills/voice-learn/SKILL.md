# Обучение голосу

Цель — чтобы твои тексты всё больше звучали как тексты человека.

## Когда человек поправил твой текст

1. Сначала исправь текст.
2. Для каждой правки стиля добавь строку в таблицу `memory/voice-edits.md`:
   `дата | где (канал или формат) | было (фраза) | стало (фраза) | вывод одной строкой`.
   Вывод — о стиле, а не о смысле. Плохо: «поменяла цифру». Хорошо: «фраза короче, без вводного
   слова».
3. Правки фактов, цифр, имён и смену задачи не записывай — это не голос.
4. Покажи одну строку: «Правка голоса записана: <вывод>».
5. Когда человек одобрит финальный текст, спроси: «Добавить в библиотеку?»

## Когда человек одобрил текст без правок

Спроси: «Добавить в библиотеку?» При «да» — раздел «Добавить в библиотеку».

## Добавить в библиотеку

1. Сохрани текст целиком в `agent/voice-library/ГГГГ-ММ-ДД-тема.md` по формату из `README.md`
   этой папки.
2. В `memory/voice-edits.md` увеличь «Текстов в библиотеке с последнего пересмотра» на 1.
3. Стало 5 — сделай «Пересмотр голоса».

## Пересмотр голоса

1. Прочитай строки `memory/voice-edits.md` после последнего пересмотра и 5 последних текстов
   из библиотеки.
2. Найди закономерности: что человек правит постоянно, какие приёмы повторяются в его текстах.
3. Бери только то, что встретилось минимум дважды. Догадки не предлагай.
4. Предложи 2–5 правил одним сообщением:

   ```
   В библиотеке 5 новых текстов. Предлагаю добавить в voice.md:
   1. <правило> — видно в правках: <было → стало>
   2. <правило> — из текстов: <цитата>
   Добавить?
   ```

5. После «да» допиши правила в подходящие разделы `agent/voice.md`. После «нет» ничего не
   меняй.
6. В любом случае обнули счётчик и запиши сегодняшнюю дату в «Последний пересмотр voice.md».

## Чего не делать

- Не правь и не удаляй тексты в библиотеке.
- Не меняй `agent/voice.md` без «да».
- Не записывай в правки личные данные, суммы, имена третьих лиц.
