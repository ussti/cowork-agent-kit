# Новый проект

Тематический проект — отдельный проект в Cowork со своей папкой, инструкциями, журналом и
решениями. Профиль, правила и уроки у всех проектов общие: их агент берёт из основной папки. Так
контекст здоровья не смешивается с контентом, а человека не приходится описывать заново.

Проекты не навязывай. Предлагай, только когда тема действительно отдельная и к ней будут
возвращаться.

## Шаг 0. Где ты сейчас

Посмотри, какие папки подключены к сессии.

- **Первая папка — основная папка агента** (в ней лежат `agent/USER.md` и `memory/lessons.md`).
  Значит, человек ещё в основном проекте. Ничего не создавай. Спроси, как назвать проект, и
  объясни пять действий, подставив название:

  1. В Finder (на Windows — в Проводнике) рядом с основной папкой агента создать пустую папку
     «<имя основной папки> — <название>».
  2. В Cowork: Projects → «+» → Use an existing folder → выбрать эту папку. Назвать проект
     «<название>».
  3. В настройках нового проекта добавить вторую папку — основную папку агента. Первой должна
     остаться новая папка.
  4. В инструкции нового проекта вставить строку:

     ```
     Перед любой задачей прочитай CLAUDE.md в первой папке проекта, затем CLAUDE.md основной папки агента, и следуй им.
     ```

  5. Начать в новом проекте задачу и написать `/new-project`.

  На этом остановись.

- **Первая папка пустая или почти пустая, вторая — основная папка агента.** Это новый проект,
  иди к шагу 1.

- **Первая папка уже содержит `CLAUDE.md`, который начинается с «# Проект:».** Проект уже
  заведён. Скажи об этом и ничего не перезаписывай.

- **Основной папки агента среди подключённых нет.** Попроси добавить её второй папкой в
  настройках проекта (действие 3 выше) и начать задачу заново.

## Шаг 1. Интервью

Спроси:
1. Как назвать проект? (Если уже назвали — не переспрашивай.)
2. Зачем он: какая цель или какие задачи будут повторяться?
3. Какие файлы и данные туда пойдут?
4. Есть ли правила только для этого проекта? (Например, «в контенте всегда пиши моим голосом»,
   «в финансах всё в рублях».)

Если проект про здоровье, деньги, документы или других людей, скажи прямо:
«Всё, что лежит в папке, агент читает и отправляет модели при работе. Не клади туда пароли,
номера карт, сканы паспорта, полные медицинские карты. Выписки и анализы — только те, которые
действительно нужны для задачи.»

## Шаг 2. Файлы проекта

В первой папке проекта создай:

- `CLAUDE.md`:

  ```
  # Проект: <название>

  Цель: <одна-две строки из ответа 2>.

  Это отдельный проект личного агента. Профиль, правила и уроки бери из основной папки агента
  (вторая папка этого проекта): agent/USER.md, agent/rules.md, memory/lessons.md.
  Журнал и решения этого проекта веди здесь: journal.md, decisions.md, archive/.
  Другие проекты не открывай и не упоминай.

  ## Правила проекта
  - <из ответа 4, или «пока нет»>
  ```

- `journal.md` и `decisions.md` — скопируй заголовки и пояснения из `memory/journal.md` и
  `memory/decisions.md` основной папки, без записей. В журнале строка «Последняя уборка:
  <сегодня>».
- пустые папки `archive/`, `inbox/`, `outputs/`.

Сначала покажи дерево файлов и дождись «да».

## Шаг 3. Отметка

Добавь в `memory/decisions.md` основной папки запись: дата, «Новый проект: <название>», зачем.

## Шаг 4. Проверка

Попроси человека начать новую задачу в этом проекте и спросить «Какой это проект и что ты обо мне
знаешь?». Агент должен назвать проект и пересказать профиль из основной папки.
